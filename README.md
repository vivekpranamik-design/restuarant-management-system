1. Project Description

The Restaurant Management System is a simple Python-based console application designed to manage food orders and generate customer bills.

This project allows customers to view the food menu, place orders, calculate the total amount, and generate bills with 5% GST.

2. Objectives
To display the available food menu.
To allow customers to place food orders.
To calculate the price according to quantity.
To maintain a record of ordered items.
To generate customer bills.
To calculate GST (5%) automatically.
3. Technologies Used
Programming Language: Python
Concepts Used:
Dictionary
List
While Loop
For Loop
If-Else Statements
Functions of Input and Output
Exception Handling
Basic Arithmetic Operations
4. Features
Display Food Menu: Shows available food items and their prices.
Place Order: Allows customers to select food items and enter quantities.
Generate Bill: Displays ordered items, price, quantity, subtotal, GST, and final bill.
Exit: Closes the restaurant management system.

7. Main Menu

The application provides four options:

Display Food Menu
Place Order
Generate Bill

8. Billing Calculation

The system calculates the bill using the following formulas:

Subtotal:

Price × Quantity

GST:

Subtotal × 5 / 100

Grand Total:

Subtotal + GST

Beginner-friendly Python project.
10. Conclusion

The Restaurant Management System is a basic Python project that demonstrates the practical use of fundamental programming concepts. It helps in understanding loops, conditional statements, lists, dictionaries, and exception handling through a real-world restaurant billing example.
